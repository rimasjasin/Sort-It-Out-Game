# Sort It Out

![A yellow sticky note with the words Sort It Out sits above six colorful team buttons, while two cartoon coworkers cheer and confetti flies around them.](cover.png)

A short team game where two coworkers decide which department should handle everyday work tasks.

## Play it

**https://rimasjasin.github.io/Sort-It-Out-Game/**

You need one phone or computer and two players. Share the screen on a video call or sit side by side.

## How to play

1. Tap **Start**.
2. Read the task on the sticky note out loud.
3. The player whose turn it is says which team should handle it, then taps that team.
4. A right answer moves you to the next note. A wrong answer fades that button so you can try again.
5. Sort all 10 notes together with as few mistakes as you can.
6. Tap **Play again** for a new set of notes.
